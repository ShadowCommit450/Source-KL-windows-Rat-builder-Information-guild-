## 🔍 What is a Windows RAT Builder?

A Windows RAT Builder is a software framework used to generate customizable Remote Access Trojans (RATs). These builders are commonly analyzed by malware researchers, penetration testers, and threat intelligence teams to understand attacker methodologies and improve malware detection systems.

Modern RAT builders may include:

- Keylogger modules
- Remote desktop monitoring
- File manager access
- Password recovery features
- Payload crypters and obfuscators
- Anti-VM and anti-debug protections
- Windows Defender bypass techniques
- Registry persistence systems
- Command-and-control (C2) communication
